## 1 · Frame

**Subject** — 一把「长在房间里的卷尺」。领域是现场测量：卷尺、激光测距仪、测量钉、墨线、建筑尺寸标注。需求本身很具体，我只补了边界：量的是室内 0.05–6 m 的**点到点直线距离**；面积、角度、体积、导出都不在这一版里。

**Viewer & context** — 戴 PICO OS 6 头显的人，站着或走两步，在自己家、办公室或工坊里量桌子、门洞、窗、柜子的空位。一只手可能正扶着东西；会伸手、会下蹲。**不假设长时间佩戴：戴上，一分钟内量完，摘下。** 尺上读数在 0.3–5 m 都要读得清；仅有的控制面在伸手可及处（约 0.6 m）。输入是手柄和手势并重；验收在 PICO 模拟器里用系统指点（鼠标 = 注视，点击 = 捏合）完成。

**The single job** — 把现实里的两个点，变成一个**敢拿去用**的距离读数。「敢用」= 看得见量的是哪两点 + 数值 + 这次量得有多准。列表、设置、持久化都只是为这一件事服务。

**Spatial justification** — 形态结论：**Full Space · Stage · Mixed**。这不是偏好：透视、平面识别、空间锚点、手柄/手部追踪只在 Full Space 可用，且被量的东西比任何窗口都大。逐任务如下。

| Core task | Affordance | Why spatial beats flat | 2D counterfactual |
| --- | --- | --- | --- |
| 把钉落在真实的点上 | Position + Body | 点本来就在房间里；立体视觉加 6DoF 的工具尖或射线直接给出三维位置，侧身走一步就能复核，不占手 | 手机 AR 测量：隔着一块屏去点，有视差和手指遮挡，沿视线方向的深度看不见；或者卷尺加手抄数字 |
| 在原位读两点间的距离 | Scale + Distance | 尺带 1:1 铺在被量的东西上，数字就挂在那一段上，不必在「名字」和「位置」之间来回对照 | 平面列表「A–B 1.204 m」：钉超过三颗，就得靠记忆把名字对回实物 |
| 复核与微调精度 | Depth + Motion | 侧过身就能看出钉有没有离面、偏了多少；尺带跟着微调实时伸缩 | 屏幕放大镜加重新点击；深度方向的误差在单一视角里看不出来 |
| 给任意两颗钉连线 | Direction + Position | 直接指向那两颗钉，连出来的就是它们之间那条尺 | 两个下拉框，或 N×N 距离矩阵。**坦白说，总览全部配对时矩阵更高效**——所以本设计不做「全部配对常显」，只在选中一颗钉时展开它到其余各钉的候选线 |
| 重开后找回 | Position + Time | 钉和尺回到原处，可以接着量，也可以复核 | 只剩一张历史数字表，指认不了当时量的是哪里 |
| 单位、语言、撤销、清除 | 无 | 没有空间收益 | 普通 2D 控件就够 → **保持 2D，缩到最小**，只需决定它放在哪 |

**Hard inputs（需求方给定，不可协商）**

1. Full Space + MR 透视（Stage · Mixed），不是 Shared Space 窗口应用。
2. 空间锚点就是测量点；放 N 个锚点，**任意两个**之间的距离都能在空间里标出来（线 + 读数）。
3. 手柄和手势都要能**精确**放置；放置精度是产品的核心质量。
4. 所有 2D UI 用 PICO SpatialUI 组件；字体 Noto Sans（拉丁）+ Noto Sans CJK SC（中文）。
5. 中英双语，应用内可切换（默认跟随系统）；公制 m / cm / mm 与英制 ft / in，应用内可切换。
6. 至少一条完整的「落钉 → 看到距离」流程只靠系统指点就能走完（模拟器验收）。
7. **用户口味**：空间媒介必须是承重的。测量工具本身要是房间里的真实 3D 物体，带物理行为——钉像钉在表面上，尺带有真实刻度、拉的时候会伸、会吸附、会落定，准星像工具尖。悬浮的 2D 数字面板只能是少数：少、小、每一块都要有理由。
8. 短会话：打开即可落第一颗钉，不做引导向导、不做模式菜单。

**Assumptions**

| Assumption | Confidence | What changes if wrong |
| --- | --- | --- |
| 一次会话 2–12 颗钉、1–8 条尺 | 中 | 若常态超过 30 颗：需要分组与会话管理，尺身上要加列表 |
| 可达精度：手柄触测 ±2–3 mm；手柄射线细瞄 ±3 mm + 0.15%·距离；系统指点（注视、手部射线、鼠标）±8 mm + 0.5%·距离；捏合点触测 ±8 mm | 低（未做设备验证） | 只改公差模型的常数和默认档位；「每个读数自带 ±」这条契约不变 |
| 平面识别给出带语义的四边形及其顶点；落点用解析的双面求交得到，不依赖平面碰撞体的朝向；空间网格只作补充 | 高（模拟器上 spike 已验证；真机的平面密度与稳定性未知） | 真机上平面更碎或抖动：角/边吸附降级，只保留钉吸附和垂直/水平吸附 |
| 注视 + 捏合模式下应用拿不到悬停位置，只有点击瞬间的三维点 | 高（设计规范明示） | 该模式没有实时准星；所以主流程必须在「点一下、再点一下」下完整成立 |
| 手柄尖端相对追踪位姿的偏移已知，或可一次标定 | 低 | 触测改为「虚拟探针尖对准」，档位由触测降为细瞄 |
| 微调不重建锚点：钉的位置 = 锚点位姿 + 局部偏移（毫米到几厘米），偏移随钉保存 | 中 | 若锚点重定位后朝向不稳、把偏移带偏：改为关闭微调时重建一次锚点（0.3–1.0 s，期间显示「钉牢中」） |
| Stage 里的附着面板可承载 SpatialUI 组件（含对话框、菜单、提示条、引导气泡）并可用玻璃材质 | 中（玻璃材质 spike 已验证；对话框、菜单、提示条、引导气泡未验证） | 对话框与菜单改成同尺寸的普通附着面板，材质退为 `fillPrimary` 深色实底 |
| 默认单位随系统语言与地区：中文 → m；en-US → ft·in；其余 → m | 中 | 改成一律默认 m |
| 只量点到点直线距离 | 高 | 若要面积/角度：信息架构要给「测量类型」留位置 |
| Noto Sans 与 Noto Sans CJK SC 随应用打包（OFL 许可），不依赖系统字体 | 高 | — |
| 惯用手默认右手，尺身停在视野左下 | 中 | 用户可抓住尺身拖到别处；不单独做设置项 |

## 2 · Explore — alternatives

**Direction generation** — inline-isolated。主会话的代理名额只有设计、开发、测试三个，本轮不能再开并行探索者，所以按技能的回退方案在同一上下文里做：先给三条赛道各定一句硬约束，然后**一条写完整了再开始下一条**，写的时候把该赛道的约束当成唯一前提，最后才横向比较。三条赛道共享 §1 的全部硬输入（含用户口味）。

三条赛道的硬约束：

- **A · 拉尺** — 工具是一卷尺：每次测量都是从一颗钉到另一颗钉的一次「拉」，站在原地用指点或射线打到识别出的表面上；控制只住在一个尺身实物上。
- **B · 触针** — 工具就在手里：每个点都用探针尖（手柄尖或捏合点）真的碰上去；两只手就是一把卡尺；所有界面长在工具上，世界里不放面板。
- **C · 放样** — 房间本身是工具：识别出的面、边、角给出「座」，用户是在候选里选而不是瞄；尺寸以建筑标注线的方式画在房间上；界面是一条跟头的细条。

### Direction A — 拉尺（Pull-tape）

**Concept** — 房间里只有三样东西：钉、尺带、尺身。对准一个点按下，一颗钉「咚」地坐到表面上，钉里探出一小截尺头；再对准第二个点按下，尺带从第一颗钉拉过去、绷一下、落定，读数牌滑到尺带中间。量完就是这样，两下。尺带是真尺带：黄底黑刻度，1 cm / 5 cm / 10 cm 三级刻线按真实比例印在上面，整米处一格红标；两颗钉同在一个面上时尺带平躺在那个面上，跨空时沿自身轴线转向观看者。

- **精确放置** — 分两步：先**落**，再**校**。
  - 手柄：远处用射线打到识别出的表面，准星贴面、随法线倾斜；扳机半按进入 4:1 减速细瞄，全按落钉，位置取按下前 40–120 ms 的中值，抵消扣扳机带来的抖动。够得着的地方（约 12 cm 内自动接管）直接用手柄尖去碰，位置取手柄位姿本身、不投影到拟合平面——这是最准的一档。
  - 手势：注视 + 捏合先粗落（应用拿不到注视悬停，只拿到捏合瞬间的三维点）；随后捏住钉头拖动，手的相对位移按 4:1 传给钉，沿所在表面滑动——绝对位置靠眼，精细位移靠手。够得着的地方用捏合点直接触测。
  - 任意输入都可用：选中钉后的小牌上有两个步进器，按 1 mm 一格左右、前后挪。
  - 吸附：靠近已有的钉、识别面的角和边时磁吸过去；拉尺时接近垂直或水平会吸到正交位。
- **怎么知道量得多准** — 准星外圈是稳定环，手越稳越收紧，收到与内圈合一即「稳」。每颗钉落下时定一个档（触测 / 细瞄 / 粗瞄，另有吸附、偏远、未保存标记）；每条尺的读数后面跟一个 ± 公差，由两端的档与距离合成；公差达到 1 cm 时读数末位变淡。
- **任意两钉** — 一条规则：**上一次碰的那颗钉是尺头，下一次落的或碰的地方是尺尾。** 新落的钉自动成为尺头；点一颗已有的钉也把它变成尺头，同时它到其余各钉的距离以虚线候选一并亮出，再点另一颗钉就把那一条「拉实」。量完一条尺后回到空手状态，不自动连成折线（要连续量：点一下上一颗钉即可）。不做「全部配对常显」。
- **删除与撤销** — 选中钉 → 小牌上删除（钉弹出，连着的尺先收回）；选中读数牌 → 收回这条尺；尺身上有撤销（最近 20 步）；全部清除在「更多」里，带确认对话框。
- **控制住在哪** — 只有一个**尺身**：一个带厚度的黄黑色仪器实物（约 19 × 8 cm），懒跟随在视野左下、伸手可及。正面是它的面板：一格读数窗（当前或最近一条尺）、单位分段（m / cm / mm / ft·in）、撤销、吸附开关、更多（语言、全部清除、退出）。除此之外没有常驻面板。
- **读数** — 读数牌是骑在尺带中点上的深色实底小牌，白色大数字 + 单位 + ±；朝向观看者、保持竖直；0.45–3 m 之间保持恒定视角大小，更远才缩小；尺太短放不下时移到尺带一侧并拉一条引线。
- **持久化** — 钉即空间锚点，随落随存；重开后钉在原位升起，尺带从尺头重新拉到尺尾，顶部一条提示「已找回 3 颗钉、2 条尺」。不在这个空间里的钉隐藏并提示，可一键清除。
- **失败与边界** — 无表面：准星变空心虚线圈，按下不落钉。超过 3 m：准星变橙色虚线并标「精度下降」，仍可落，档位降级。锚点创建失败：钉以空心「未保存」形态留下，本次照常测量，提示可重试。定位丢失：钉与尺去色、读数冻结。手柄休眠 / 手不可见：准星淡出，3 秒后提示。
- **只靠系统指点** — 点表面 → 钉；再点表面 → 钉 + 尺 + 读数。点钉 → 选中；小牌上的步进器微调。全程不需要实时准星。

**Signature** — 尺带的「拉—吸—定」：拉的时候刻度随长度一格格展开，吸附时轻轻一抖，落定时横向弹两下并把读数牌盖在中点。

**Main risk** — 注视模式下没有实时准星，尺带在瞄准时不会跟着伸（只在落第二颗钉的瞬间射过去），签名效果在这一模式下打折；远距离射线的精度上限取决于平面拟合质量；尺身是懒跟随物体，看向地面时可能挡在视野偏左处。

### Direction B — 触针（Touch-probe）

**Concept** — 不隔空瞄，直接碰。惯用手里的工具是一根探针：手柄前端伸出一根 6 cm 的虚拟钢针，徒手时是捏合点上的一枚「顶针」环。走到跟前，针尖碰到真实的点，扣扳机或捏合，一颗图钉被按进那个位置。第一颗图钉按下后，一根细线从它那里牵在你的针尖上，你拿着线头走过房间，线跟着手实时伸长，手背上的小表盘跳着读数；碰到第二个点再按一下，线系住。两只手同时拿探针时就是一把卡尺：两个针尖之间出现一根刚性横梁，读数在梁中央，不落任何东西就能读；两手同时按下则一次落两颗图钉加一根线。

- **精确放置** — 接触即真值：位置取追踪到的针尖本身，不依赖平面拟合，也不依赖透视画面的配准。针尖上有稳定环；提交位置取按下前的中值。落错了：针尖碰住图钉、握住侧键把它「拔起来」，挪到新位置松开。
  - 手柄：±2–3 mm 量级，本方向的主力。
  - 手势：捏合点触测，±8 mm 量级；探针换成顶针环，其余相同。
  - 够不着的地方（天花板、柜顶深处）：摇杆前推把探针「抽长」成一根最长 3 m 的伸缩杆，杆尖贴到识别面上——这其实就是射线，档位标为粗瞄。
- **怎么知道量得多准** — 每颗图钉帽上的形状区分触测与伸缩杆；读数后带 ±；表盘上的稳定环在按下前给出预期。
- **任意两钉** — 针尖碰一颗图钉就「挂上线」，拿到另一颗图钉上碰一下就系住。也可以用卡尺横梁临时读任意两点而不留痕迹。
- **删除与撤销** — 针尖碰住线、握侧键一扯即断；图钉同理拔掉。撤销在副手手柄的按键上；全部清除在副手托盘里，带确认。
- **控制住在哪** — 全在工具上：惯用手背上的表盘（实时读数 + 单位）；副手手柄翻向面部时出现一个三键小托盘（单位、撤销、更多）。徒手时表盘与托盘分别附着在两只手的手背一侧（避开系统「看手心」手势）。世界里没有任何面板。
- **读数** — 线中点挂一枚黄铜小牌，按 0.3–0.7 m 近读设计；超过 1.5 m 只保留数值。
- **持久化** — 图钉即锚点；重开后图钉在原位、线重新系上。
- **失败与边界** — 针尖丢失（手柄休眠、手出视野）：线头从手里「掉下去」垂在上一颗图钉上，手回来再碰一下图钉接上。锚点创建失败：图钉变空心，可拔起重按。定位丢失：全部去色冻结。
- **只靠系统指点** — 没有手就没有探针。只能另做一套替身：指点表面落图钉、点钉再点钉系线，表盘和托盘退化成一小条跟头的面板。能走通，但已经不是这个方向了。

**Signature** — 拿在手里走过房间的那根线，和两手之间的卡尺横梁。

**Main risk** — 硬需求第 6 条只能靠一套与主体验完全不同的替身流程满足；手部追踪的接触精度撑不起「触针 = 精确」的承诺；每个点都要走到、够到、甚至蹲下，和「一分钟量完」相悖；界面依赖副手，而副手常常在扶东西；手柄尖端偏移需要标定。

### Direction C — 放样（Layout）

**Concept** — 房间自己就是量具。打开后，识别出的每个面的轮廓像弹墨线一样扫出来，角和边上出现一个个小凹「座」。用户不需要瞄得准：指点或视线扫到附近，最近的座亮起并把准星吸过去，按下，一颗测量钉打进座里。精度来自几何而不是来自手，所以手柄、手势、注视、鼠标得到的是同一个精度。尺寸不是物体而是**标注**：两端各一条离面 6 cm 的尺寸界线，中间一条带斜杠端符的尺寸线，数字骑在线中央，按隔着房间也能读的大小来排。

- **精确放置** — 吸附优先：角 > 边 > 面上任意点。两面交线（墙与地、墙与墙）和三面交点也是座。另有「净距」：先点一面墙，再点对面的墙，直接给出两个平面之间的垂直距离，一颗钉都不用落——这是房间尺度上最准的量法。不在座上的点要长按才能落，落下的是空心钉，标为低可信。
  - 手柄与手势没有区别对待：都是「扫到附近 → 吸住 → 按下」。
- **怎么知道量得多准** — 精度就是识别器的精度：每个面带一个拟合置信度，标注线末端用实心或空心端符表示；读数后带 ±。用户改善不了它，只能知道它。
- **任意两钉** — 焦点扇：选中一颗钉，它到视野内其余各钉的尺寸线同时展开（淡色）；点其中一条把它「钉住」常显。非轴向的一对钉额外给出水平分量与垂直分量。
- **删除与撤销** — 点尺寸线上的数字 → 取消钉住；点钉 → 小标签上删除；撤销与全部清除在细条上。
- **控制住在哪** — 一条跟头的细条，停在视野下缘：当前读数、单位、撤销、更多。除此之外没有面板，也没有任何实物。
- **读数** — 数字高约 1.2° 视角，2–5 m 可读；尺寸线离面抬起，避免和真实表面的纹理打架。
- **持久化** — 钉与被钉住的标注保存；每次启动平面重新识别，标注重新贴到面上。
- **失败与边界** — 面还没认出来：该区域没有座，提示「慢慢看一圈」。面更新：钉跟着面滑动。远处的面：座变淡并标注精度下降。定位丢失：标注全部虚线化。
- **只靠系统指点** — 天然成立：点在座附近即可。

**Signature** — 一进来整个房间被弹上墨线、变成一张 1:1 的图纸；点两面墙直接出净距。

**Main risk** — 精度完全交给平面识别（拟合误差 1–2 cm 量级，用户无从改进），和「精确放置是核心质量」正面冲突；真实要量的点常常不是面的角或边（墙上的一个记号、没被识别成面的物体边缘）；标注线是画上去的图形而不是有物理行为的实物，跟头细条又是一块常在视野里的 2D 面板——两处都撞上用户口味；焦点扇在钉多于 6 颗时很乱；依赖平面边界数据可得；两次启动的识别结果不同会让标注漂移。

**Decision matrix**（1–5，5 最好；Risk 一栏 5 = 风险最低）

| Direction | Task efficiency | Spatial value | PICO comfort | Domain fit | Risk | Distinctiveness |
| --- | --- | --- | --- | --- | --- | --- |
| A 拉尺 | 5 — 两下出读数；任意两钉也是两下 | 5 — 尺带是原位、等比例的实物 | 4 — 站在原地量；尺身懒跟随 | 5 — 就是卷尺 | 4 — 每种输入都有完整路径 | 4 |
| B 触针 | 3 — 每个点都要走到、够到 | 5 — 身体即量具 | 2 — 近焦、弯腰、常要双手 | 4 — 卡尺与拉线 | 2 — 指点路径是另一套产品；手势精度不足 | 5 |
| C 放样 | 4 — 在座上极快，离了座就慢 | 3 — 图形叠加，没有实物 | 4 — 原地、大字 | 4 — 建筑标注 | 2 — 精度与可用性都押在平面识别上 | 3 |

**Chosen: A 拉尺** — 它是唯一一个在全部输入方式下（手柄、手势、注视、模拟器鼠标）都用**同一套**心智模型走完主流程的方向；两下出读数，对得上「戴上、量、摘下」；工具本身是有刻度、会伸、会吸、会定的实物，正中用户口味；「上一次碰的是尺头，下一次碰的是尺尾」一条规则就覆盖了任意两钉。

**Rejected**

- **B 触针** — 输在硬需求第 6 条和手势精度：模拟器里没有手可碰，替身流程已经不是这个方向；徒手接触只有约 ±8 mm，撑不起它的核心承诺；每个点都要身体到位，不适合一分钟会话；界面依赖常常不空闲的副手。**保留它最好的一部分**：够得着时用手柄尖或捏合点直接触测，作为 A 里最高的精度档（不引入双手卡尺和手背界面）。
- **C 放样** — 输在「精度不归用户管」和口味：平面拟合误差直接成为读数误差且无法微调；标注线与跟头细条都是 2D 图形而非实物；离开角和边就变成二等公民。**保留三样**：角/边/钉与垂直/水平吸附作为 A 的辅助（可关）；选中一颗钉时展开到其余各钉的候选线（只在选中期间，不常显）；启动识别时让识别出的面闪现一次轮廓，让人知道哪里能量。净距、分量拆解不进这一版。

## 3 · Plan

选定方向 A「拉尺」，并入 B 的触测档、C 的吸附与候选线。下面每一条都已按 dev spike 在模拟器上核对过的平台现实收紧（见本节末「依赖 SDK / 模拟器行为的假设」）：

- **没有 3D 文字**：所有数字都住在附着面板上（读数牌一条尺一块）。尺带上只有刻线和红标，不印数字；钉上不标字母。
- **锚点创建是异步的（0.3–1.0 s）**：钉落下后先进入「钉牢中」，再变为已保存或未保存；期间照常可用。
- **平面是陆续报上来的（模拟器里首批约 20 s，全部约 45 s）**：识别不阻塞操作，认出一块就能在那一块上落钉。
- **注视 + 捏合 / 模拟器鼠标拿不到悬停位置**：系统指点路径下没有实时准星，靠「点一下落钉」和「按住拉出」两种方式完成；有追踪射线（手柄、手部射线）时才有贴面准星。
- **模拟器可能只有 2–4 fps**：所有动效按时间而不是按帧推进，任何状态都不依赖动效才能看懂。
- **面板物理尺寸：1 dp = 0.8 mm（缩放 1）**：跟着物体的面板要随观看距离缩放并朝向头部。

**Materials / depth** — 尺身面板是 `Material.Regular` 玻璃，嵌在尺身的深色面板槽里；面板里的读数窗是 `fillPrimary` 底。钉牌、尺牌是 `Material.Regular` 玻璃根（露出 3 dp 的边）+ `plateInk` 内卡。菜单用组件默认的 `Thick`；对话框与提示条在 Stage 里是按组件规格自建的附着面板，材质都用 `Thick`。读数牌、候选距离片、准星标签是 3D 物体的一张脸，直接面对任意透视背景，用 `plateInk` 实底。深度只用真实深度：物体在它真实的位置上；选中的钉沿法线抬起 6 mm；牌子离面 3 cm，按 Surface sizing 的朝向规则转向观看者；不在玻璃上叠 `zOffset`。

**Glass premise** — 所有玻璃都来自 SpatialUI 的 `Material.Regular` / `Thick`，不自造半透明底或模糊。并且**每块玻璃背后都有受控的深色衬底**（尺身的面板槽、牌子的内卡），不让玻璃直接叠在不可控的透视画面上承载文字。预览里房间画面只是透视的替身，刻意调暗以便在 Web 版玻璃上判断对比度，它不是应用的 token。实机更正（2026-10-02）：`Material.Regular` / `Thick` 本身是一张浅色磨砂片，背后的深色衬底并不会让它变暗（尺身面板实测约 `#8A8988`）；衬底只保证玻璃不直接叠在不可控的画面上。所以玻璃上的文字是深色的，并且一律用 `labelPrimary`。

### Signature element

**尺带的「拉—吸—定」。** 一条有真实刻度的黄色尺带：拉的时候刻线随长度一格格展开、读数牌骑在尺尾跟着数；靠近角、边、钉或垂直 / 水平位时轻轻一抖吸过去；落定时横向弹两下，读数牌滑到中点盖下去。系统指点路径下没有瞄准过程，同一套动作压缩到落第二颗钉的那一刻：尺带从尺头「拉出去」到尺尾（0.6–1.1 s），读数从 0 数上来。

周围保持安静：钉只有钢和黄两种颜色、不带字；整个应用只有一个常驻面板（尺身），其余面板都是选中某个物体时才出现的一小块；没有列表、没有标签页、没有装饰性光效。

### Surface sizing

全部是 Stage 里的附着面板，用户不能调整大小。尺寸按 1 dp = 0.8 mm（缩放 1）给出；「恒定视角」= 实体缩放取 `观看距离(m) ÷ 0.8`，距离钳制在 0.45–6 m 之间（整个量程内读数大小不变；实测 3 m 的上限让 4–6 m 处的公差行只剩 5–6 px），超过 6 m 不再放大。单块面板高度不超过 720 dp（模拟器实测，再高会被裁掉）。

**朝向规则**（房间里的面板：读数牌、候选距离片、钉牌、尺牌、准星标签）— 绕竖直轴转向头部，再向头部俯仰，俯仰钳制在 ±60°，不滚转（面板的横边始终水平）；头部离面板的竖直线不到 0.1 m 时保持上一次的转向。朝向由应用每帧写到面板的承载实体上，不用 `LookAtComponent`（实测它只转画面、不转指点命中面）。

**表面规则**（同样这些面板）— 面板转好朝向之后，四个角都要在每个识别面朝头部一侧至少 2 cm（只算角的垂足落在该面四边形外扩 5 cm 之内的面）。不满足时沿「头部 → 面板中心」这条线把面板往头部拉，直到满足；缩放跟着距离走，所以它在视野里的位置和大小不变。下限：离头不小于 0.45 m；钉牌、尺牌不小于其锚点距离的一半。钉牌、尺牌还要站在它在视野里盖住的东西前面：距离不大于被盖住的最近的读数牌、距离片、尺带或钉的距离减 5 cm。牌子离头比锚点近到 0.8 倍以内时，从锚点到牌子最近一边的中点画一条引线。

### Layout

唯一的主焦点是**正在量的那条尺和它的读数牌**，它在世界里、在被量的东西上。其余一切按使用频率往外退：选中才出现的小牌贴着物体；设置类控制收在尺身上、停在视野左下角；全局消息在视野上缘。密度上限：同一时刻常驻面板 1 块（尺身），随物小牌至多 1 块，提示条至多 1 条；读数牌每条尺 1 块，一次会话最多 20 条尺（读数牌面板池 20 块；第 21 条不创建，提示条说明）；互相遮挡、或被自己的尺带穿过时，沿各自的尺带错开并换侧（中点 → 36% / 64% → 24% / 76%，每个位置试尺带两侧）；同屏超过 8 块时未选中的只显示数值一行。钉多的时候靠三条规则保持清楚：只有用户亲手拉出的尺才存在（不自动连全部配对）；候选线只在选中一颗钉时出现、最多 6 条；选中一颗钉时与它无关的尺退到 55% 不透明度。

### 交互模型

**一条规则**：上一次碰的那颗钉是尺头，下一次落的或碰的地方是尺尾。

| 动作 | 结果 |
| --- | --- |
| 点一下表面 | 落一颗钉。没有尺头时它成为尺头（钉上探出一截尺头）；已有尺头时它是尺尾，尺带拉过去并落定，回到空手 |
| 点一下钉 | 选中它：它成为尺头，出现钉牌，同时到其余各钉（尚未连尺的，最近 6 颗）的候选线与距离片亮出。再点它一下取消选中 |
| 选中一颗钉后点另一颗钉，或点一块候选距离片 | 这两颗钉之间拉出一条尺 |
| 按住表面或钉，拖动，松开 | 「按住拉出」：按下处是尺头（落新钉或用按住的那颗钉），拖动时尺带实时伸长、准星与吸附可见，松开处是尺尾。任何输入方式都可用，是系统指点路径下看到实时尺带的方式 |
| 点读数牌 | 选中这条尺，出现尺牌；再点别处取消 |
| 钉牌上打开「微调」后拖动这颗钉 | 钉沿所在表面滑动，手的位移按 4 : 1 传给钉 |
| 钉牌上的两个步进器 | 沿表面两个方向每次挪 1 mm |
| 尺身上的撤销 | 撤回最近一步（落钉、拉尺、删除、收回、微调；最多 20 步；一次「按住拉出」算一步） |

**输入通道与精度档**

| 通道 | 何时 | 准星 | 提交 | 落下的档 |
| --- | --- | --- | --- | --- |
| 触测 | 手柄尖或捏合点离目标不超过约 12 cm（够得着） | 工具尖本身：实心菱形 + 紧环；不吸附角和边（工具尖就是真值），只吸附已有的钉 | 扳机 / 捏合 | 触测 ◆ |

| 指点 | 注视 + 捏合、模拟器鼠标等系统指点 | 没有应用准星。钉、读数牌和面板控件上有系统的悬停高亮；表面上没有 | 系统给出的点击三维点 | 粗瞄 ○ |

主次：手柄的首选是**触测**（够得着）与**半按细瞄**（够不着）；手势的首选是**注视落点 + 校位**与**按住拉出**（终点由手的相对位移控制，比视线准）；够得着时用捏合点触测。

**系统拖动怎么变成尺尾**（注视 + 捏合、模拟器鼠标）— 这条通道下应用拿不到指向射线：系统拖动手势只给出手的三维位移（`SpatialDragValue.dragAmount`）。规则：按下时记下「头部 → 按下点」这条指向线；之后手每移动 1 cm，指向线绕头部转约 1.2°（相当于一支以肩为轴、0.5 m 长的指示杆）；指向线与识别面的交点就是准星与尺尾的位置，照常吸附、照常看稳定环。应用拿得到指向位姿时（手柄射线、手部射线）直接用那条射线，不走这个换算。拖动校位更简单：手的位移投影到钉所在的表面后乘 0.25。换算系数是起始值，待真机调。

**怎么知道量得多准** — 三处：瞄准时看稳定环；每颗钉落下时定档；每条尺的读数后面跟一个 ±。公差模型（设计常数，待真机标定）：触测 2 mm（捏合点 8 mm）；细瞄 3 mm + 距离的 0.1%；粗瞄 8 mm + 距离的 0.4%；吸附到角或边 6 mm；超过 3 m 加倍。一条尺的公差 = 两端平方和开根，**只向上取**到下一档：2、3、5、8 mm；1、1.5、2、3、5、8 cm；10、15、20、30、50 cm；超过 50 cm 写「> 50 cm」。单颗钉的公差（钉牌徽标）用同一把梯子。公差达到 1 cm 时读数最后一位变淡；达到 10 cm 时最后两位变淡（英制：整个英寸数变淡）。

**吸附**（尺身上可关）— 优先级：已有的钉 > 识别面的角 > 识别面的边 > 垂直 / 水平（相对尺头）。吸附到角或边后一旦微调，就不再算吸附。按通道分两套判定：

- **有准星的通道**（手柄射线、手部射线、按住拉出）：用视角半径（钉约 1°、角约 0.9°、边约 0.6°、垂直 / 水平约 0.85°），并且只吸附没被当前命中表面挡住的座；可以吸到别的面上的座，因为准星在按下之前就把座显示出来了。
- **指点通道**（注视 + 捏合、模拟器鼠标，没有准星）：只吸附**被点中的那个面**自己的角和边，以及在这个面内相对尺头的垂直 / 水平位；绝不吸到别的面上。除视角半径外再加一个距离上限：点中的点到座不超过 40 mm（角）或 30 mm（边、垂直、水平），两条同时满足才吸。吸附后在钉落下时补一个 0.8 s 的座标记代替波纹：角 = 沿两条边各一道 40 × 2.5 mm 的短杠，边 = 沿边一道 80 × 2.5 mm，垂直 / 水平 = 朝尺头方向 60 mm 的引导线；角与边用 `interaction`，垂直 / 水平用 `passable`，下面垫 `bladeEdge`。
- 触测通道只吸附已有的钉（不变）。

### Components

- **钉** — 任务：标出一个测量点，并说明它有多可信。数据：锚点位姿、所在平面的语义、落下时的档（触测 / 细瞄 / 粗瞄）、是否吸附、是否偏远、保存状态（钉牢中 / 已保存 / 未保存）、微调偏移。形态：常态、悬停（钉帽外一圈白环）、尺头（抬起 + 黄环 + 尺头）、钉牢中、未保存、冻结、找回中、弹出。
- **尺带** — 任务：把两颗钉之间的距离以 1 : 1 的刻度铺在现场。数据：两端钉的当前位置、单位制。形态：实时（一端跟着准星，带钢钩）、拉出中、落定、选中（描边加粗）、冻结（去色虚线）、收回中、找回中。
- **读数牌** — 任务：给出这条尺的读数和公差。数据：两端距离、公差、单位、两端的偏远 / 未保存标记、定位状态。形态：两行（数值；公差）、拉出中（数值随长度数上来，第二行为「…」）、选中（黄色描边）、警示（第二行前加 ▲ 并变橙）、冻结（去色，第二行前加 ⦸）。可点。
- **准星与准星标签** — 任务：告诉人「按下去钉会落在哪、落得多稳」。数据：指针命中的平面与点、稳定度、吸附结果、到用户的距离、识别是否完成。形态：贴面 / 稳 / 吸附（角、边、钉、垂直、水平）/ 触测 / 细瞄 ×4 / 偏远 / 没有表面 / 表面还在识别。
- **尺身与尺身面板** — 任务：全局控制与一个稳定的近处读数。数据：最近或所选的那条尺、实时拉尺距离、识别进度、单位、吸附开关、撤销栈、语言。读数窗第一行是语境（正在准备… / 识别表面中 · n / 可以落钉 / 拉到下一点 / 正在拉… / 最近 · ±x / 所选 · ±x / 定位丢失 · 已冻结），第二行是数值。
- **钉牌** — 任务：微调或删除一颗钉；说明它的档位。数据：所在平面语义、档位与单颗公差、两个方向的偏移（mm）。形态：收起 / 微调展开。
- **尺牌** — 任务：说明这条尺两端各是什么档；收回它。数据：读数、公差、两端档位。
- **候选线与候选距离片** — 任务：选中一颗钉时，一眼看到它到其余各钉的距离，并能一下把其中一条拉实。数据：其余钉（未与它连尺的，按距离取最近 6 颗）。
- **提示条** — 任务：说一句全局的事。数据见「文案」。带动作的两条：未保存 →「重试」；钉不在此处 →「清除它们」。定位丢失那条不自动消失。
- **对话框** — 清除确认（高风险，必须明确确认）；能力不可用（阻断）。
- **更多菜单** — 语言（当前值写在同一行）、全部清除…（没有钉时禁用）、退出空间尺。
- **引导气泡** — 首次使用的两句话；量出第一条尺或点「知道了」后永不再出现。
- **面轮廓** — 任务：让人知道哪些表面已经能量。数据：平面检测的新增事件。

### SpatialUI Web component map

预览里 `sui-augment` 只是「带 `Material.Regular` 玻璃根的附着面板」的 Web 替身（库里唯一能给自由面板提供该材质的元素）；产品里没有使用 Augment、Toolbar、TabBar、Subwindow 这些窗口附件。

产品里的承载方式（模拟器实测，2026-10-02）：`Menu` / `SubMenu` 在 Stage 的附着面板里可用，照用。`AlertDialog` 在 Stage 里不出内容，`SnackbarHost` 返回「Stage 不支持」，所以清除确认、能力不可用和提示条是预先建好的附着面板，用 SpatialUI 的 `Button` / `Text` 按组件规格拼成（规格见 Surface sizing 对应两行）；预览里仍以 `sui-alert-dialog` / `sui-snackbar-host` 作替身。

### 反馈、持久化与边界

- **声音与触感**：落钉 = 一声短促的「咚」+ 手柄 `Press` 触感；吸附 = 一声轻「嗒」+ `Step` 触感；尺带落定 = 一声「咔」；收回 = 短促的回卷声；保存失败、没有表面 = 系统失败音。能用系统内置音效的用内置的；模拟器里感受不到触感，所以每一项都有对应的可见变化。
- **持久化**：钉即空间锚点，创建成功后与它的档位、连线一起保存；单位、语言、吸附开关、「引导已看过」也保存，并且在任何面板文字出现之前读出来——宁可让读数窗空着只转圈，也不先用默认语言或默认单位画一遍。重开：先「准备中」，随后已保存的钉在原位升起、尺带从尺头重新拉到尺尾，提示条报数。微调不重建锚点：钉的位置 = 锚点位姿 + 局部偏移（毫米到几厘米），偏移随钉保存，步进与拖动即时生效（不等锚点的 0.3–1.0 s）。读数永远由两端钉的当前位置算出，所以重定位之后同一条尺可能差零点几毫米。未保存的钉只在本次有效。
- **超过 3 m**：允许落钉，但准星和读数明确标出「偏远」，公差加倍。
- **读数的第一出口是尺身**：尺带落定的那一刻，尺身读数窗就显示「最近 · ±x」和数值，读数牌随后到位。模拟器在 2–4 fps 时新建一块面板要几秒才出现，所以读数牌、候选距离片、钉牌、尺牌、准星标签都从预先建好的面板池里取：出现 = 改位置与可见性，不在那一刻新建；消失 = 隐藏，不移除。
- **数量**：按 2–12 颗钉、1–8 条尺设计。上限 20 条尺（读数牌面板池 20 块，全部面板约 35 块，在 spike 验证过的 42 块之内）：第 21 条尺不创建，尺尾那一下照常落钉并成为新的尺头，提示条「最多 20 条尺 / 先收回一条，再拉新的。」。钉不设上限。

### 模拟器验收路径（只用系统指点）

1. 打开应用 → 读数窗「正在准备…」→「识别表面中 · n」；认出的面闪现轮廓（模拟器里可能要等 20–45 s）。
2. 鼠标点一块已认出的表面 → 钉落下，套环虚线转动（钉牢中）→ 变实心（已保存）；钉上探出尺头。
3. 再点一处 → 第二颗钉落下，尺带从第一颗拉到第二颗，读数从 0 数到终值，读数牌停在尺带中点，显示数值与 ±。
4. 点任意一颗钉 → 钉牌 + 到其余各钉的候选线与距离；点另一颗钉或距离片 → 这两颗之间拉出一条尺。
5. 钉牌里「微调」→ 步进器逐毫米挪动，读数实时变化；「删除」→ 钉弹出、连着的尺收回；尺身「撤销」恢复。
6. 尺身分段切 m / cm / mm / ft·in；「更多」→ 语言切换、全部清除（带确认）、退出。
7. 退出后重新打开 → 钉和尺在原位找回。
8. 可选：在表面上按住拖动再松开 → 尺带实时拉出（取决于模拟器是否送达拖动手势）。

第 2–4 步的前提是假设 1 成立（系统指点点到表面时应用收得到 Spatial Tap）。这一条已在模拟器上用真实注入的捏合验证（2026-10-02，命中点与解析求交相差 0.2–0.6 mm），备用瞄准不需要。

测试代理可用调试广播注入一条合成指向射线来走「射线通道」（准星、稳定环、实时尺带、吸附）；spike 已确认 adb 的触摸与鼠标事件不会变成 Spatial Tap，也点不到面板，所以「系统指点」这一段只能由人在模拟器窗口里点。

## 4 · Critique (before build)

**Generic-default simulation** — 一句「做个 MR 测距应用」最容易得到的东西：一块悬浮的玻璃面板，上面有「添加点」按钮、点与距离的列表、单位下拉框和一个设置页；空间里是几颗发光小球，之间连着细细的青色线，线旁边飘着数字；深色底配一个青色强调色；首次启动先过三页引导。换成「家具摆放」「管线标注」，这套东西几乎不用改。

**Where the plan risked that default, and what I changed.**

1. 尺身一度长成了「设置面板」：读数、列表、五个按键。改为一件仪器——一格读数、一排单位、三个键，其余进「更多」；不做列表。
2. 钉上原本有 A / B / C 字母牌，面板里也处处引用字母。字母牌是又一层悬浮的 2D 东西，而且平台没有 3D 文字。全部去掉：钉就是钉，读数挂在尺上。
3. 「发光小球 + 细线」换成钢钉加黄色套环、带真实刻度的尺带；尺带上原计划印的数字做不出来（没有 3D 文字），改为只留刻线层级和整米红标。
4. 尺带原本平躺在表面上，掠射角度下会细到看不见。改为绕轴朝向观看者，并设最小视角宽度；钉也设了最小视角。
5. 签名动作原本只发生在「瞄准的过程」里，而注视 + 捏合和模拟器鼠标恰恰没有瞄准过程。把「拉出—落定」搬到落第二颗钉的那一刻，并增加「按住拉出」这个任何输入都能做的连续手势。
6. 「正在扫描房间」的整屏等待页改为不阻塞的渐进识别：认出一块面就能在那块面上落钉，尺身上只多一行字。
7. 强调色不是随手挑的青色：黄色来自尺带本身。默认的琥珀色警示与它太近，警示改为橙色；黄底上的文字显式用墨色。
8. 钉牌、尺牌原本是直接叠在透视画面上的玻璃。改为玻璃根 + 深色内卡，内卡上的控件全部用固定的 on-ink 颜色，对比度不再取决于房间。
9. 单位从「设置里的下拉框」改为仪器正面的四段分段；语言是低频项，留在「更多」里。
10. 全部配对的距离矩阵在平面上其实更高效（§1 已承认），所以没有把它硬搬进空间：只做「选中一颗钉时的候选线」。

走查中发现并已修补的问题见补丁记录。**仍然存在、如实记录的差距**：

1. Web 版分段控件按内容定宽，预览里「m」一段约 39 px 宽，小于文档要求的 64 dp；这是库的行为，实现以文档为准。
2. 预览无法区分手柄与手：半按细瞄用 Shift 代替，触测用「距视点 1 m 内」代替，捏合点触测的 ±8 mm 档没有单独呈现。
3. 预览不模拟真实深度、遮挡、面板随距离缩放的物理尺寸，也没有声音与触感。
4. 十条尺连满五颗钉时仍有个别读数牌相互压住（错开规则只试五个位置）。
5. 没有为钉和尺的数量上限设计提示：设计范围是 2–12 颗钉、1–8 条尺，面板数只在 spike 里验证到 42 块；如果开发实测有硬上限，需要回到设计补一条「已满」提示。（2026-10-02：已补，上限 20 条尺，见 §3「反馈、持久化与边界」。）
6. 备用瞄准（头瞄准星 + 尺身「落钉」键）只有文字规格，预览里没有做；只有假设 1 不成立时才需要它。（2026-10-02：假设 1 已验证，这一条作废。）
