# 空间尺 Spatial Ruler — 模拟器试用指南

（2026-10-05 第 4 轮起 UI 改为图标优先：机身只剩 数字 / 撤销 / 更多 / 单位，吸附开关和语言切换都在"更多"里，钉和尺选中后是图标条。）

应用已装在专用模拟器 **emulator-5556**（AVD `PICO_6.1_Ruler`，窗口标题 "PICO Emulator - 6.1.0"，桌面左侧那一个）上，场景是模拟器自带的卧室。打开应用后先看到卷尺机身和一条一句话的引导（✓ 关掉，或拉出第一条尺后自动消失）。

## 模拟器怎么操作

| 想做的事 | 眼手模式（默认） | 手柄模式 |
| --- | --- | --- |
| 指向 | 移动鼠标（= 注视点） | 移动鼠标（= 手柄射线，准星贴在表面上） |
| 落钉 / 点按钮 | 单击（= 捏合） | 单击（= 扳机） |
| 按住拉出尺带 | 按住左键拖动再松开 | — |
| 走动 | W / S 前后，A / D 左右，Q / E 下上 | 同左 |
| 转头 | 按住右键拖动 | 同左 |
| 切换模式 | 底部工具栏第一个按钮旁的 ▾ → Eye Gesture Mode / Right Controller Mode | 同左 |

模拟器窗口要有焦点（点一下窗口）才会以 60 fps 运行；没焦点时只有 2–4 fps。

## 一分钟流程

1. **落第一颗钉**：对准地面或墙上的一个点，单击。钢钉落下、套环变实心表示锚点已保存，钉上探出一截尺头。
2. **拉尺**：对准第二个点再单击。尺带从第一颗钉拉过去、刻度展开、读数从 0 数到终值，读数牌立在尺带中点上，机身读数窗同步显示。
3. **任意两钉**：单击任意一颗已有的钉 → 它成为尺头，到其余各钉的虚线候选和距离片亮出；再点另一颗钉或距离片，这两颗之间拉出一条尺。再点一次尺头取消。
4. **微调**：点钉 → 图标条（○ ±公差 · 移动 · 垃圾桶 · 关闭）→ 点"移动"展开 ‹ › ˅ ˄ 步进器，每次挪 1 mm，机身读数实时变化；也可以按住钉拖动（4:1 减速）。精度符号 ◆ 触测 / ● 细瞄 / ○ 粗瞄。
5. **按住拉出**：在表面上按住拖动，带刻度的尺带实时伸长，松手落定。
5b. **拖动钉微调末端**：按住任意一颗钉拖动，钉抬起、原位留一个幽灵环、准星跟着落点走（带角/边/钉吸附标记），连着的尺带和读数实时变化，松手落定。移动放慢时自动进入 1:4 细调（准星旁显示 ×4），快速移动回到 1:1；拖到别的表面上会改贴那个面；一步撤销回原位。按住钉上探出的**尺头钩子**拖动则是拉出一条新尺。
6. **单位 / 语言 / 吸附**：机身上的 m / cm / mm / ft·in 分段即时换算所有读数；"更多"（⋯）里：🌐 / 中文 / EN 语言分段、吸附开关、🗑 Clear all、退出。
7. **删除与撤销**：钉的图标条里垃圾桶删钉；点读数牌出现 ± 和收回图标；机身"撤销"（最近 20 步）；"更多" → Clear all（带确认）。
8. **重开**：退出后再打开，钉和尺在原位找回（锚点保存在设备上）。

## 读数里的信息

- 读数牌只显示数字；精度用末位变淡表示（≥ 1 cm 淡一位，≥ 10 cm 淡两位），▲ 表示超过 3 m 或未保存；点读数牌或钉能看到 ± 公差。
- 手柄模式下准星外圈是**稳定环**：手越稳越收紧，收到与内圈合一并变绿即可落钉；扳机半按进入 4:1 减速细瞄（真机），准星旁显示 ×4。

## 真机才能验证的部分

手部追踪（捏合点、手部射线）和手柄的模拟量扳机、触感、音效在模拟器上没有数据或感觉不到，代码路径已按 SDK 写好并用合成输入测过，需要在 PICO 设备上验证。
